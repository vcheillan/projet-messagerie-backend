Je fais ici une note concernant les choix qui ont été faits dans ce projet :
1) J'ai choisis de considérer les otpions marquer comme lu et supprimer un message car ce sont les otpions qui sont à mes yeux les plus utiles au quotidien. 
2) Concernant le design css, c'est relativement sobre et j'ai utilisé l'aide de l'IA pour pouvoir aller relativement rapidement sur la partie frontend. 
3) Pour la mise en place des websockets, c'est assez complexe je dois l'avouer mais cela permet de rendre interactive la messagerie ce qui est très utile. 

Je vous remercie donc pour ce semestre d'inforamtique, très utile pour comprendre les différentes interfaces du web et je vous souhaite une belle continuation !
